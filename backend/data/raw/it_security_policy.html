Acme Corp IT Security Policy

Document ID: IT-SEC-001  |  Version: 3.2  |  Effective: 2024-01-15  |  Owner: Chief Information Security Officer

1. Purpose and Scope

This policy establishes mandatory security controls for all Acme Corp employees, contractors, and third-party vendors who access Acme Corp information systems. Compliance is mandatory and non-compliance may result in disciplinary action up to and including termination of employment or contract.

2. Password Requirements

ParameterRequirement
Minimum length14 characters
ComplexityMust include uppercase, lowercase, digit, and symbol
Maximum age90 days
HistoryLast 12 passwords cannot be reused
Multi-Factor AuthenticationMandatory for all accounts

3. Device Security

All endpoints (laptops, mobile devices) that access Acme Corp resources must:

  • Have approved endpoint detection and response (EDR) software installed and active
  • Maintain OS and application patches within 7 days of release for critical vulnerabilities
  • Use full-disk encryption (BitLocker for Windows, FileVault for macOS)
  • Be enrolled in Acme Corp Mobile Device Management (MDM) system
  • Automatically lock after 5 minutes of inactivity

4. Remote Access

All remote access to Acme Corp internal networks must use the company-approved VPN client. Split tunnelling is prohibited. Employees working from public networks (cafes, airports) must use the VPN at all times.

⚠ Important: Connecting to Acme Corp systems from a personal device that has not been approved via the BYOD programme is strictly prohibited.

6. Incident Reporting

All suspected security incidents (phishing, malware, data loss) must be reported to security@acmecorp.internal within 1 hour of discovery. Employees must not attempt to remediate incidents independently.

7. Acceptable Use

Acme Corp systems may be used for legitimate business purposes only. Prohibited activities include cryptocurrency mining, personal cloud storage sync, and installation of unapproved software. All internet traffic is monitored and logged for security purposes.

8. AI Tool Usage

External AI services (including but not limited to ChatGPT, Claude, Gemini) may not be used to process Acme Corp Confidential or Restricted data without explicit written approval from the CISO. Violation of this policy constitutes a data breach and will be treated accordingly.
